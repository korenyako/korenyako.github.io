# korenyako.github.io Knowledge Base

Вики проекта, поддерживается LLM.

Персональный сайт-портфолио Антона Кореняко (продуктовый дизайнер, Турин).
Next.js 14 + статический экспорт, деплой на GitHub Pages. Бэкенда и БД нет —
весь контент лежит в TypeScript-модулях в `src/data/`.

- [design-system.md](design-system.md) — токены цвета, типографические пары, ширины раскладки
- [animation.md](animation.md) — AnimationObserver и анимированные обложки Netok/Kotic
- [decisions.md](decisions.md) — принятые решения и причины
