# Анимации

## AnimationObserver

`src/components/AnimationObserver.tsx`, монтируется один раз в корневом layout.
Единственный клиентский JS, нужный обложкам, — благодаря этому `ProjectCard` и
сами обложки остаются серверными компонентами.

Что делает:

1. Находит все `[data-animate]` и вешает `IntersectionObserver` (`threshold: 0.25`).
2. При появлении в вьюпорте добавляет класс `in-view` — он и запускает CSS-анимации.
3. Если элемент объявил CSS-переменную `--animate-cycle`, класс периодически
   снимается и вешается заново, перезапуская последовательность. Иначе элемент
   снимается с наблюдения после первого показа.
4. `MutationObserver` подхватывает узлы, появившиеся позже (клиентская навигация,
   кнопка Replay в песочнице).
5. Циклы останавливаются, когда элемент уходит с экрана, и не стартуют при
   `prefers-reduced-motion: reduce`.
6. Если `IntersectionObserver` в браузере нет — всем элементам сразу ставится
   `in-view`, чтобы контент не завис в стартовом состоянии.

Перезапуск класса выбран вместо `animation-iteration-count: infinite` осознанно,
причина — в [decisions.md](decisions.md).

## Обложки Netok и Kotic

`src/components/covers/` — по паре «TSX с инлайновым SVG + колокированный CSS».
Серверные компоненты, никакой анимационной библиотеки.

Общая механика обоих CSS-файлов:

- Правила **вне** `@media (scripting: enabled)` описывают финальный, собранный
  логотип. С выключенным JS обложка показывает готовый логотип, а не пустоту.
- Внутри `@media (scripting: enabled)` логотип скрыт до появления `in-view`.
- `animation-fill-mode: backwards`, никогда `forwards`. Оставшийся после анимации
  transform держит SVG на композитном слое, растеризованном один раз, и логотип
  в покое выглядит мылом. Стартовые состояния живут только в `from` кейфреймов.
- Вся тонкая настройка (задержки, длительности, easing) вынесена в переменные в
  начале файла. Полный прогон Kotic — около 2.45s.

Геометрия Netok перерисована, а не скопирована: в `netok-logo.svg` знак — один
слитый `<path>`, отдельные части анимировать нельзя. Узлы воссозданы как
обводки-кольца, рёбра буквы N заканчиваются точно на осевой линии кольца
(r = 99.026), иначе круглый торец обводки залезал бы в отверстие узла. Подробный
разбор с числами — в шапке `NetokCover.tsx`.

Обложка подключается через `heroComponent` в данных проекта; `ProjectCardMedia`
сопоставляет id с компонентом. `hero` при этом остаётся фолбэком для страниц,
где обложка не рисуется.

## Песочницы

`/dev/netok` и `/dev/kotic` — предпросмотр обложек с кнопкой Replay
(`CoverPreview` перемонтирует блок с новым `key`, `AnimationObserver` ловит новый
узел и играет с нуля). Контейнер повторяет `ProjectCardMedia` один в один.

Страницы попадают в статический экспорт и **публично доступны** на боевом сайте.
Ниоткуда не залинкованы. См. [plans/roadmap.md](plans/roadmap.md).

## Прочая анимация

- `animate-fade-in` на обёртках карточек — кейфреймы из `tailwind.config.ts`.
- `animate-scroll` — бесконечная лента логотипов в `BrandStrip` (30s linear).
- `AnimatedHeadline` — смена слова на главной по `setInterval`, 2.5s.
- Шапка прячется при скролле вниз через хук `useScrollDirection`.
